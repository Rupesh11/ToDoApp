 To-Do List App

A simple and interactive To-Do List application built using JavaScript, HTML, and CSS.

Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Tasks are saved using Local Storage and persist after page refresh

Technologies Used

- JavaScript (DOM manipulation & event handling)
- HTML
- CSS

How It Works

- Tasks are stored in an array and rendered dynamically on the page
- Each task includes a text value and a completed status
- Data is saved in Local Storage to maintain persistence
- Event listeners are used to handle adding, deleting, and updating tasks

Key Concepts Used

- DOM manipulation
- Event delegation
- Local Storage
- Conditional rendering
- Array methods
